## Grass Valley Kaleido module

This module connects to various Kaleido multiviewers with a TCP connection using the Kaleido Remote Control Protocol.

The device is available in different versions, either under the Miranda or Grass Valley brands.

The module has been tested with a Miranda KS-910, firmware version 500.0075 and Miranda X16 on firmware version 10.21.

It should also work with Kaleido Quad, Kaleido Alto, Kaleido K2, Kaleido X and Kaleido Modular but these haven't been tested yet. Please let us know if you use it successfully with any of them.

### Commands supported

- Recall presets saved in the device. The names are read from the device on initialization.
- Set tally: preview and program
- Set alarm state: yellow and red (colored text and border)
- UMD text (including Companion variables)
